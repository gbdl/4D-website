# Checks and measured outputs

This directory contains outputs of numerical, data, build and browser checks. Their scope is recorded with the measurements; they are not certificates of a global Einstein metric.

| Record | Check |
|---|---|
| `evidence.json` | Bundled identities, statistics, matched grids and 63 paired comparisons; generated by `python3 tools/export_evidence.py` |
| `audit-supplement.json` | Saved cusp, area, integral and correction fields; generated by `python3 tools/build_audit_supplement.py` |
| `source-arrays.json` | Hashes and reductions of original saved tensors, face geometry and core incidence; requires the larger source arrays |
| `geometry.json` | Deterministic copy-membership, cusp-inversion and analytic black-hole checks; generated by `python3 tools/check_geometry.py` |
| `evaluator.json` | CPU float64 metric values and first/second derivatives at 12 points per state, two interface pairs, analytic controls and deliberately incorrect cases |
| `evaluator-fast.json`, `evaluator-standalone.json` | Saved-derivative checks and operation without the original research repository |
| `site-links.json` | Relative links and JSON parsing |
| `browser.json` | Desktop/mobile interactions, keyboard controls, static fallbacks and rendering |
| `privacy.json` | Historical public-file and binary-metadata scan from 25 October; includes files since removed |
| `publication-review.json` | Current pre-publication checks, privacy findings and verification limits |

The numerical companion's complete selected-fixture run took about 80 seconds with about 1.49 GiB peak memory on the recorded machine. It compares both frozen parameter sets with original-code reference outputs. These samples do not establish accuracy between points.

The historical browser check verified data and weight endpoints by HTTP response and file hash (and, at the time, a technical-note PDF that has since been withdrawn from the published set together with its receipt; `browser.json` and `privacy.json` still list it). It did not observe a browser download-completion event. Static fallbacks were tested using a script-free copy. These records describe a local preview on 25 October 2026. Wording in the website and repository text files changed after that date; the file hashes in `browser.json` and `privacy.json` describe that earlier snapshot. Those historical records also refer to a staging script and custom deployment workflow that have since been removed in favor of publishing directly from `main`. The retained data, figures and weight files still match those hashes. Current pre-publication checks are recorded separately in `publication-review.json`, and `site-links.json` is regenerated from the current page.

Some receipts refer to larger source arrays that are not included in this compact repository. They preserve provenance; only commands whose inputs are bundled can be repeated from this repository alone. Internal narrative assessments are not part of the published evidence.
